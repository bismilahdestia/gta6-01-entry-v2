Porto Alba — an open-world crime game in the spirit of GTA 6: a sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, a wanted level, police chases, missions and a story. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
# open http://127.0.0.1:8123
```

## Controls

- **WASD / Arrows** — drive & walk (Shift to run on foot)
- **E** — steal a parked car / get out of a car
- **Mouse drag** — orbit the camera · **Click** — shoot the pistol
- **R** — reload · **Space** — handbrake · **P / F** — pause

Progress (mission, money, health, position) saves automatically to localStorage.
